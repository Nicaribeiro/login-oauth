## 🖥️ Sobre o projeto

O Login OAuth é um laboratório de autenticação que permite entrar utilizando contas Google e GitHub. O projeto explora conceitos de OAuth 2.0, gerenciamento de sessões, integração com banco de dados e automação de processos.

## ✨ Funcionalidades

- Autenticação com Google e GitHub.
- Gerenciamento de sessões.
- Validação do fluxo de autenticação.
- Integração com banco de dados.
- Automação com GitHub Actions.

## 🛠️ Tecnologias

`JavaScript` · `HTML` · `CSS` · `OAuth 2.0` · `Cloudflare Pages Functions` · `Cloudflare D1` · `GitHub Actions`
